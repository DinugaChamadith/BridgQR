## 🤝 Code of Conduct

This project and everyone participating in it is governed by a simple principle: **be kind and respectful**.  
By participating, you are expected to uphold this code. Please report unacceptable behavior by opening an issue or contacting the maintainers directly.

We expect contributors to:

- Use welcoming and inclusive language
- Be respectful of differing viewpoints and experiences
- Gracefully accept constructive criticism
- Focus on what is best for the community and the project

## 💡 How Can I Contribute?

### 🐛 Reporting Bugs

Before creating a bug report, please check the [existing issues](../../issues) — someone may have already reported it. If not, open a new issue and include as much detail as possible:

- **A clear and descriptive title**
- **Steps to reproduce** the problem
- **Expected behavior** vs. **actual behavior**
- **Screenshots or screen recordings** if applicable
- **Browser and OS** (e.g., Chrome 122 on Windows 11, Safari on iOS 17)
- **Console errors** (if any)

> ⚠️ **Security note:** If you find a security vulnerability, please **do not** open a public issue. Instead, contact the maintainers privately.

### ✨ Suggesting Enhancements

We love new ideas! To suggest an enhancement:

1. Open an issue with the **`enhancement`** label.
2. Clearly describe the feature and **why it would be useful**.
3. Provide examples of how it might work (mockups, sketches, or references are welcome).
4. Mention any alternatives you've considered.

### 🧑‍💻 Your First Code Contribution

Unsure where to start? Look for issues labeled:

- **`good first issue`** — simple tasks for newcomers
- **`help wanted`** — we'd love assistance on these
- **`documentation`** — improvements to the README or guides

If you're still unsure, feel free to ask in an issue — we're happy to help you get started.

## 🛠 Development Setup

BridgQR is intentionally a **single‑file** application. No build tools, no package managers, no bundlers.

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A code editor of your choice (VS Code, Sublime Text, etc.)
- *(Optional)* A local static server for testing clipboard features
